# Arqueo de caja

Script en Python que calcula el total de dinero en caja a partir de la cantidad de billetes de cada denominación. Lo hice como primer proyecto de mi portafolio, basado en el control de caja que realizo en mi trabajo.

## Qué hace

- Pide la cantidad de billetes de 100, 50, 20 y 10 soles.
- Calcula el subtotal de cada denominación.
- Muestra el total contado en soles.

## Cómo ejecutarlo

1. Instala Python 3 (python.org).
2. Descarga este repositorio.
3. En la terminal, dentro de la carpeta del proyecto, ejecuta:

```
python mini_arqueo.py
```
